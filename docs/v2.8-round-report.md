# v2.8.0-beta.1：单手作战与移动端操作架构

2026-11-02 · Android 公开 Beta · 基于 v2.7.0-beta.1

## 本轮判断与借鉴

手机端的「一指可玩」必须同时解决两件事：移动摇杆能从拇指真实落点起手，且另外三种主动操作不会要求玩家持续使用另一只手。现有《深渊小队》已支持无手动指向时自动攻击，但移动热区锁在固定左下侧，技能和终极需另外点击。此次提供完整的**可选**单手路径，而不更改旧版双摇杆。

参考：Android 官方的多点触控指引强调追踪稳定 pointer ID、独立处理 UP/CANCEL；Game Accessibility Guidelines 推荐允许玩家重排触摸控制的高频操作位置。这里采用低风险的替代方案：浮动摇杆可从大部分战斗空白区起手，并自动处理需要第二根手指的技能操作。来源：
- https://developer.android.com/develop/ui/views/touch-and-input/gestures/multi
- https://gameaccessibilityguidelines.com/allow-interfaces-to-be-rearranged/

## 玩家可感知的改变

1. 设置页「无障碍与舒适度」保留左手布局，同时增加独立的「单手作战」开关，**默认关闭**。两个选项可同时开启。
2. 单手作战开启时，触摸战斗空白处即建立浮动摇杆（不限原先左侧热区），指示圈绘制在实际落指处，移动/松手都沿用稳定 pointer ID 的既有逻辑。菜单、顶栏、闪避/技能/终极按钮仍保留独立热区，不会被浮动摇杆吞掉。
3. 单手模式不需要玩家持续手动瞄准，继承现有自动射击；技能根据敌人距离、首领与队友生命状态自动触发；终极为首领、大规模敌群或危急支援保留，不在空场消耗。闪避仍是手动时机决策，原来的按钮继续可点。
4. 新增 HUD「单手 · 自动技能」状态提示；设置页玩法说明随开关显示相应操作提示，避免玩家不知道自动技能是有意开启。
5. 开关存在独立 SharedPreferences 键，与左手布局、特效和音频设置一起即时持久化；游戏存档与局域网 Codec 协议字段均不改变。

## 工程隔离与保障

- 新增纯 Java `core/OneHandAssist`：只读 Game 的敌人、队友与冷却状态，返回技能/终极建议位掩码；不写游戏状态、不消耗随机数。单机与局域网都仍经 `Session.input` / `Session.ultimate` 的权威入口；在线客户端用时间闸门防止等待状态同步期间重复发送命令。
- 新增 `OneHandAssistTest`：空场不浪费冷却、近战和首领、群怪、治疗支援、技能未就绪、倒地、掉线、非战斗与确定性均有覆盖。
- 旧双摇杆默认路径未修改热区；左手布局镜像逻辑保留。
- Android versionCode **2801**，versionName **2.8.0-beta.1**；Codec 仍为 v11。

## 仍需真人验收

自动能力会降低部分操作负担，所以**两种操作模式的实际难度并非完全等价**；游戏未开放竞争排行榜。需要用实体设备测试超宽屏、黑边、右侧拇指和弱网条件，特别是自动终极的主观节奏、单手长局疲劳与无障碍用户习惯。此版保持 Beta，不声称达到专业无障碍认证。
